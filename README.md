# HoYo Version Tracker

**Live:** https://mentalplatypus.github.io/HoyoVersionTracker/

One page that tracks version updates for Genshin Impact, Honkai: Star Rail and Zenless Zone Zero: what's live now, when the next version arrives, livestream times, redeem codes that still work (including the short-lived livestream codes), a timeline of recent and upcoming versions, and the latest official news. Dates come from HoYoLAB announcements, checked every hour, and are shown in your own time zone. You can also add the upcoming dates to your calendar.

A fan-made project, not affiliated with HoYoverse.

Made by [David Wang](https://mentalplatypus.github.io/).
